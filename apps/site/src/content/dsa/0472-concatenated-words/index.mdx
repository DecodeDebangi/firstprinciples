## The problem

You get a list of different words. Return every word that is the joining of **two or more** shorter words from the same list (a word may be used more than once).

For `go, at, goat, to, gate, togo` the answer is `goat, togo`: goat is go + at, and togo is to + go. "gate" can't be made from the list.

## The key question

> **What does the check for one word really need to know at each position?**

Only whether a run of cuts can land there. If it can, every listed word starting at that position extends the reach, and a trie finds all of them in one walk. Positions are checked once each, so nothing is retried.

## Approach 1: Try every split, recursively

For each word, try every first piece that is a listed word, then split the rest the same way, backing up when a choice leads nowhere. Count the pieces so a word doesn't count as made of itself.

<Viz client:visible approach="recursive" />

<Complexity time="exponential" space="O(L)">
**Time.** The same tail of a word can be split again and again from different first cuts: for words like a, aa, aaa, …, the number of tries grows **exponentially** with the length.

**Space.** The recursion: **O(L)**.

**What it wastes:** retrying the same tails. Whether "aaab" can be split is worked out again after every different way of cutting the front.
</Complexity>

## Approach 2: Shorter words in a trie, and which positions a cut can reach (optimal)

Sort the words by length and go through them shortest first. For each word, mark position 0 as reachable; from each reachable position, walk the trie along the word, and each time a stored word ends, mark the position after it. If the end is marked, the word counts. Then add it to the trie.

<Viz client:visible approach="trie" />

<Complexity time="O(Σ L²)" space="O(total letters)">
**Time.** Each of a word's L positions starts at most one trie walk of up to L letters: **O(L²)** per word.

**Space.** The trie and one list of marks: **O(total letters)**.
</Complexity>

## Common mistakes

- **Counting a word as made of itself.** It must be two or more pieces; inserting it into the trie only after checking it guarantees that.
- **Checking words in the given order.** A word can only be made of shorter ones, so go shortest first.
- **Stopping a trie walk at the first word that ends.** Longer words may start at the same position, like "go" and "goat".
