## The problem

You get a list of words. The **score** of a string is how many words in the list start with it. For each word, add up the scores of all its non-empty prefixes, and return these totals in order.

For `car, cat, cart, dog` the answer is `[8, 7, 9, 3]`. For car: "c" starts 3 words, "ca" 3, "car" 2 (car and cart), so 3 + 3 + 2 = 8.

## The key question

> **Where is "how many words start with this prefix" already stored?**

In a trie that counts: each node's count is exactly that number for the prefix spelled on its path. A word's prefixes are the nodes along its own path.

## Approach 1: Count every prefix in a map

For every word, copy out each of its prefixes and count it in a map. Then, for every word, look up each of its prefixes and add the counts.

<Viz client:visible approach="map" />

<Complexity time="O(Σ L²)" space="O(Σ L²)">
**Time.** A word of length L has L prefixes of lengths 1 to L, and copying them costs about L²/2 letters: **O(Σ L²)** over all words.

**Space.** The map's keys are all those copies: **O(Σ L²)**.

**What it wastes:** copying. The prefix "car" is built letter by letter again for every word that has it.
</Complexity>

## Approach 2: A trie that counts words through each node (optimal)

Insert every word, adding 1 to each node on its path. Then walk each word's path again, adding up the counts.

<Viz client:visible approach="trie" />

<Complexity time="O(total letters)" space="O(total letters)">
**Time.** Each word is walked twice, one step per letter: **O(total letters)**.

**Space.** At most one node per letter: **O(total letters)**.
</Complexity>

## Comparing the approaches

Race two approaches on the same input. Both share one clock that ticks once per operation, so the one doing extra work visibly falls behind.

## Common mistakes

- **Counting each prefix once per word, not once per occurrence.** A word that appears twice counts twice; the trie handles it with no special case.
- **Scoring while inserting.** A word's score depends on words inserted later; insert everything first.
- **Using the end-of-word marks.** The score counts words that start with the prefix, which is the pass-through count, not whether a word ends there.
