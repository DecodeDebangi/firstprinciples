## The problem

Design a class built from a list of `words`. Its query `f(pref, suff)` returns the largest index of a word that starts with `pref` and ends with `suff`, or −1 if there is none.

In the animation, write queries as `prefix suffix`. For the words `ape, apple, maple`: `ap e` gives 1 (both ape and apple fit; apple is later), `ma le` gives 2, and `a x` gives −1.

## The key question

> **A trie follows a word from its beginning. How can one walk check its beginning and its ending?**

Change what's stored so both appear at the front. A key like "le#maple" starts with an ending, then the whole word, so "le#ma" is a prefix of it exactly when maple ends with le and starts with ma.

## Approach 1: Check every word, from the last

For each query, look at the words from the last one back, and return the first that starts with the prefix and ends with the suffix.

<Viz client:visible approach="scan" />

<Complexity time="O(n · L) per query" space="O(1) extra">
**Time.** A query may check every word, comparing up to L letters at each end: **O(n · L)**.

**Space.** Nothing beyond the words: **O(1)**.

**What it wastes:** rechecking all the words on every query.
</Complexity>

## Approach 2: One trie of suffix#word keys (optimal)

For each word w at index i, and each of its endings e (including the empty one), insert the key e + "#" + w, writing i on every node along the way. Later words overwrite, so each node holds the largest index. A query walks suff + "#" + pref and returns the index there.

<Viz client:visible approach="trie" />

<Complexity time="O(L) per query" space="O(n · L²)">
**Time.** Building inserts L + 1 keys of up to 2L + 1 letters per word: O(L²). Each query is one walk: **O(L)**.

**Space.** All those keys: **O(n · L²)** letters.
</Complexity>

## Common mistakes

- **Walking pref#suff.** The key starts with the ending, so the walk is suff + "#" + pref.
- **Keeping the first index instead of the largest.** Insert in order and overwrite, so later words win.
- **Forgetting the empty ending.** Without "#word", nothing would answer an empty suffix.
