## The problem

You get a string `s` of lowercase letters. Return the position of the first character that appears exactly once in
the whole string. If every character appears more than once, return -1.

For example, in `abacabad` the letters `a` and `b` repeat, and `c` (at position 3) is the first that doesn't, so the
answer is 3. In `abab` every letter repeats, so the answer is -1.

## The key question

> **How do I know whether a character repeats, without searching the rest of the string for it?**

A character might appear again right at the end, so no single left-to-right reading can decide as it goes. See
[Counting characters and string keys](/concepts/counting-characters/).

## Approach 1: Check each character against all the others

For each position `i`, scan the whole string for another copy of `s[i]`. The first position with no copy is the
answer.

<Viz client:visible approach="scan" />

<Complexity time="O(n²)" space="O(1)">
**Time.** For each of the `n` positions, up to `n − 1` comparisons: **O(n²)** in the worst case, for example when
every letter's twin is half the string away.

**Space.** Two indices: **O(1)**.

**What it wastes:** the same character is searched for again and again. A count per letter, made once, would answer
"does it repeat?" in one lookup.
</Complexity>

## Approach 2: Count first, then find the first count of 1 (optimal)

Pass 1 counts every letter into 26 slots, using `code(ch) − code('a')` as the slot. Pass 2 walks the string in order
and returns the first position whose letter has a count of 1.

<Viz client:visible approach="count" />

<Complexity time="O(n)" space="O(1)">
**Time.** Two passes over the string, one O(1) slot update or lookup per character: **O(n)**.

**Space.** 26 counts, however long the string: **O(1)**. With any characters allowed, a hash map would hold one count
per different character instead.
</Complexity>

## Common mistakes

- **Returning the character instead of its position.** The answer is the index, or -1.
- **Stopping after one pass.** During the counting pass, a count of 1 only means "not seen again yet".
- **Walking the counts in alphabet order in pass 2.** That finds the alphabetically first unique letter, not the
  first one in the string. Walk the string.
